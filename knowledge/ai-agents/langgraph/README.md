# LangGraph 源码学校课程

本学习包基于开源仓库 `langchain-ai/langgraph` 生成。

- source scope: `libs/langgraph, libs/prebuilt, libs/checkpoint, libs/sdk-py`
- reader: 有经验的后端工程师，正在系统学习 LLM/Agent 工程
- course units: 8

## 如何学习

1. 从 `learning.html` 打开静态课程页。
2. 每节课按“课程 -> 测试 -> 掌握度 -> 实验”的顺序学习。
3. 每节至少读 1 个源码入口和 2 个测试 evidence。
4. 完成 capstone 后，用 `review/test-evidence-matrix.md` 复核 claim 与 evidence。

## 产物

- `lessons/`: 完整课程。
- `quizzes/`: 每课测验和总复盘。
- `mastery/`: 掌握度检查。
- `labs/`: 最小复刻实验。
- `graph/`: entities、relations、claims、evidence 和 learning map。
- `raw/code-graph/`: Understand Anything scan/batches 与学习图。
- `review/`: 弱证据、验证报告、开放问题和测试证据矩阵。
- `wiki/`: llm-wiki 风格的简化知识图谱页面数据。
