# Capstone Lab: Mini LangGraph Agent

## 目标

用 200-400 行代码实现一个迷你 LangGraph 风格 Agent，不要求接真实 LLM，可以用 fake model。

## 功能

- StateGraph 风格 builder。
- messages reducer。
- fake chat model adapter。
- ToolNode 风格工具执行。
- interrupt/resume。
- in-memory checkpoint。
- stream debug events。

## 验收

运行测试并提交一页说明：每个功能对应 LangGraph 哪个源码 symbol 和 evidence id。
