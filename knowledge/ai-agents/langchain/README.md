# LangChain Agent Engineering Learning Pack

这是 AI Agent 代码学习知识库的第一课，研究对象是 `langchain-ai/langchain`。

本学习包的目标不是学习 LangChain API 用法，而是通过源码理解 LangChain 如何把 LLM 应用组件抽象为可组合、可观测、可批处理、可流式执行的工程模块。
